# Temp Convert

Converts temperatures locally between Celsius, Fahrenheit, Kelvin, and
Rankine.

## Command

`/TEMPCONV <temperature>[C|F|K|R] [TO|IN] [C|F|K|R]`

For example, `/TEMPCONV 32F TO C` displays `32F = 0C`. The `TO` or `IN`
keyword is optional, so `/TEMPCONV 100C K` is also valid.
