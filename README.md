# Addons

- [Alias](alias/README.md): creates persistent aliases for one or more commands.
- [AutoAuth](autoauth/README.md): identifies with NickServ after a nickname change.
- [Ignore Queries](ignore-queries/README.md): suppresses unwanted private
  messages with per-network settings and whitelists.
- [Kick Ban](kick-ban/README.md): provides channel kick-and-ban commands.
- [Mass HL Blocker](mass-hl-blocker/README.md): keeps messages visible while
  suppressing mass-highlight notifications.
- [Nicenicks](nicenicks/README.md): assigns colours to channel nicknames.
- [OperBuddy](operbuddy/README.md): provides IRC operator commands and
  server-notice routing.
- [Service Notices](service-notices/README.md): routes ChanServ and NickServ
  notices to a shared tab per network.
- [Set Away/Back](set-away-back/README.md): changes away status across connected
  networks.
- [Smart Filter](smart_filter/README.md): filters join, part, nick change and
  quit messages.
- [Temp Convert](tempconv/README.md): converts between temperature scales.
- [Uptime](uptime/README.md): displays Windows system uptime.
- [Urban Dictionary](urbandictionary/README.md): looks up definitions.
- [Whois](whois/README.md): routes WHOIS output to a per-connection tab.
- [ZNC Buffers](zncbuffer/README.md): adds menu actions to clear and replay ZNC
  buffers, while hiding the matching clear confirmation.
